# v2 foundations

v2 uses softer neutral text, with clear roles for headings, body copy and supporting details. Brand actions and status colors keep the existing semantic palette. V2 text variables are separate from v1, so both versions can appear on the same page.

Filled primary and status actions retain 600 weight. Neutral buttons, tabs, form labels and ordinary titles use 500; body text and supporting copy use 400. Individual component specs determine exact line height, weight and size. For example, EmptyState's default headline is 24px/32px, while badges are 12px regular.

## Spacing and shape

Common field and action corners are 8px; dialog and card corners are 12px. Standard fields are 40px high. Spacing follows the recorded component values, usually 8px, 12px, 16px or 24px. Component Docs show the values that apply to each primitive.

## States and motion

Interactive components distinguish hover, focus, pressed, disabled, loading and error where supported. Keep focus indicators visible. Loading effects and transitions respect reduced-motion preferences; status text remains readable when animation is disabled.

Motion is small and purposeful: it confirms an action or shows where something came from. Nothing takes longer than 200ms.

With reduced motion enabled, movement and scaling are removed and colour changes stay. Spinners slow down instead of stopping so that a busy state still reads as busy. Menu and list item highlights are instant on purpose, so keyboard navigation never lags. The rules for adding motion and the browser check that proves it live in `design/V2-MOTION.md`.
